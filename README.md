# 🔐 Password Generator & Strength Checker

A simple, fast web tool that generates strong random passwords and checks the strength of any password in real time.

## 🌐 Live Demo
👉 **https://rj-password-tool.vercel.app**

## 💡 Why I Built This
In India, the most common passwords are still 123456, password, and qwerty. People use weak passwords because they don't realize how weak their password actually is.

This tool solves two problems:
1. Makes it easy to generate a strong password
2. Instantly shows the strength of an existing password so users can improve it

## ✨ Features
- **Custom Length Password** — choose anywhere from 6 to 32 characters using a slider
- **Real-time Strength Check** — shows Weak / Medium / Strong as you type
- **Visual Strength Bar** — color-coded (red / orange / green)
- **100% Client-side** — no data leaves the browser, everything runs locally
- **Zero Dependencies** — no libraries, pure vanilla JavaScript

## 🚀 How to Run Locally
1. Clone the repo:
   git clone https://github.com/ravirajhere/password-tool.git
2. Navigate into the folder:
   cd password-tool
3. Open index.html in your browser. That's it — no installation needed.
